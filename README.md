# ECHOES OF THE PAST

A tourism website showcasing Lesotho’s cultural heritage, historic caves, ancient rock art and visitor experiences.

## Live website

https://mpopomeshach-stack.github.io/BUDAH/

## Pages

- Home: `index.html`
- About Us: `About Us.html`
- Services: `Services.html`
- Attractions: `Attractions.html`
- Gallery: `Gallery.html`
- Contact: `Contact.html`

The website uses `rara.css` and `javascript.js`. Keep all files and images in the same directory structure.

**Note:** The contact form is not connected to a message-delivery backend. GitHub Pages cannot process form submissions on its own.
